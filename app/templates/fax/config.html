受信できないときの調べ方 受信が終わると Asterisk のログに次の行が出ます。 NoOp(FAXSTATUS=FAILED PAGES=0 ERROR=... MODE=audio RATE=9600 ...) ERROR が spandsp から返ってきた失敗理由で、 同じ内容は「FAX 一覧」の履歴にも残ります。代表的なもの:
  • Unexpected message received … 通信中に順番どおりでないメッセージが届いた。上の 最大ボーレートを 9600 → 4800 と下げてみてください。
  • Timed out waiting for the first message … 相手の音が届いていない。コーデック (ulaw) と t38_udptl の設定、HGW の設定を確認してください。
  • Failed to train with any of the compatible modems … モデムの折衝に失敗。こちらも最大ボーレートを下げます。
さらに詳しい T.30 のやりとり (DIS/DCS/TCF の交換) を見るには、 /etc/asterisk/logger.conf の [logfiles] に fax レベルを足して logger reload します。 console => notice,warning,error,fax 本ツールは ReceiveFAX / SendFAX に常にデバッグ指定を付けているので、 この 1 行を足すだけでトレースが出ます (Asterisk は専用ログレベルに出力しているため、この指定が無いと どこにも出力されません)。
