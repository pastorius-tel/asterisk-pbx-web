    迷惑電話対策
    

      個別の番号は 迷惑電話ブロックリスト
      画面で登録・管理してください。ここでは、海外からの着信 (と判定
      した場合) の一律の処理を設定します。
    

    

      判定方法について: 発信者番号が日本の標準的な
      国内番号パターン (0 で始まる携帯電話・固定電話・IP電話・
      フリーダイヤル等) に一致しない場合、海外または形式不明の番号と
      みなします。個々の国番号や「+」「010」プレフィックスの正確な
      形式は回線・キャリアによって異なり確実に特定できないため、
      消去法での判定になります。実際の着信で意図通り動作しているか、
      導入後にご確認ください。
    

    

      

        
        
      

      

        
      

    

  


  

    内線番号 / 外線発信ポリシー
    

      有効にすると、内線同士のダイヤルプラン (3〜5桁) は
      先頭の桁が 2〜9 の番号にしか反応しなくなります。
      0 または 1 で始まる番号 (携帯電話 090/080/070、固定電話 03/06、
      フリーダイヤル 0120、警察 110・消防 119 などの特番) は
      内線パターンに一切マッチしないため、必ず発信ルート (トランク) 側の
      判定に回ります。内線番号は 2 以降の数字で運用してください。
    

    

      

        
        
          現在の内線ダイヤルパターン:
          {% if reserve_leading_01_for_outbound %}_NXX / _NXXX / _NXXXX{% else %}_XXX / _XXXX / _XXXXX{% endif %}
          (N = 2〜9、X = 0〜9)。
          変更後、ダッシュボードの「変更を Asterisk へ反映」を押すと
          extensions.conf が再生成されて反映されます。
          この設定は DB に保存されるため、サービス再起動やワーカー再起動でも維持されます。
        
      

    

  


  

    内線 SIP ポート
    

      内線 (PJSIP UDP transport) が待受する SIP ポートです。既定は

    Asterisk 本体のバージョン
    

      現在稼働中の Asterisk 本体 (PBXエンジン) のバージョンです。
      これは本ツール (Web管理画面) のバージョンとは別物です。
    

    

      

        現在のバージョン
        {% if asterisk_version %}
          
{{ asterisk_version }}

        {% else %}
          取得できませんでした
          
            Asterisk が起動していないか、本ツールの実行ユーザーから
            asterisk -rx が実行できない可能性があります。
          
        {% endif %}
      

    


    

      本体のアップデートは、安全のためこの画面から自動実行しません。
      ソースからの再ビルドには数分〜十数分かかり、完了時に
      全通話が切断されます。また、モジュール選択を誤ると
      現在使っている機能 (FAX 等) が失われる可能性があります。
      必ず営業時間外に、SSH 接続した状態で手動実行してください。
    

    
cd {{ app_root }}
sudo bash scripts/update_asterisk.sh

# バージョンを指定したい場合:
sudo ASTERISK_VERSION=22.10.0 bash scripts/update_asterisk.sh

    

      実行前に現在のモジュール一覧・バージョンを /root/asterisk-update-backup/
      に自動で退避します。詳細は README の「Asterisk 本体のアップデート」を参照してください。
